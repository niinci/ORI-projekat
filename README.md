# Anime Recommendation System

A Python-based anime recommendation system using **SVD collaborative filtering** and **content-based filtering** based on anime genres.

The project includes model evaluation, Precision@5 / Recall@5, and hyperparameter optimization using GridSearchCV.

### Technologies

* Python
* Pandas
* NumPy
* Surprise
* Scikit-learn

### Results

* RMSE: 1.2098
* MAE: 0.9149
* Precision@5: 0.9509
* Recall@5: 0.5626
